# linear_regression_model
Bedside Anaemia Risk Estimator: predicts a child's haemoglobin (g/dL) from bedside signs, so clinics without a lab can refer the sickest children first. Trained on 29,226 Kilifi County Hospital admissions (Kenya, 2002 to 2009). Compares SGDRegressor, LinearRegression, decision tree and random forest. Includes a FastAPI service and Flutter app.
